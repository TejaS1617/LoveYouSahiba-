# For Baboola 💗 — Birthday Surprise Website

A romantic, mobile-friendly scrapbook birthday page built with plain HTML, CSS, and JavaScript. It includes a 20-second animated story with five unique photos followed by a birthday-cake finale.

## Photos
The `assets` folder contains five photo files. The website uses these exact names in both the scrapbook and the animated story:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`

To use different pictures, replace these files while keeping the same filenames. You do not need to edit the HTML.

## Song
The `assets` folder includes `our-song.mp3`. To change it, replace that file with your own audio file and keep the same filename. Music starts only after the visitor taps the music button, because browsers restrict autoplay.

## Preview
Open `index.html` in a browser. For best results, use VS Code Live Server or run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Update your existing GitHub Pages site
1. Download and extract this ZIP.
2. Open your existing GitHub repository.
3. Upload the updated `index.html`, `style.css`, and `script.js`, replacing the old versions.
4. Upload the `assets` folder too if you want to replace the existing photos and song. If you already have your preferred photos/song there, keep those files and only replace the three code files.
5. Commit the changes and wait for GitHub Pages to redeploy.

The site remains a static website and does not collect or send personal data.
